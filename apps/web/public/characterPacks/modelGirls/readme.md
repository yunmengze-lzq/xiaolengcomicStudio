# 六模型娘多视角基准素材

这是经过分析、重新生成的基准素材，不是把收集原图直接打包。

- 六位：DeepSeek、ChatGPT、Claude、Gemini、千问、Kimi。
- 各有独立Q版和成人版，共12张PNG设定稿，包含47个全身视角，另有头像特写。
- 两套画风规范见styleGuide.json，完整文字分析见docs/modelGirlsStyleGuide.md。
- manifest.json记录身份、比例、对应PNG、尺寸、SHA-256和生成来源。generationPrompts.json保留每张提示词。
- sources/中的收集原图仅为来源留存，保留原有文字和水印；不是最终载入的角色基准图。
- 在角色与美术点击“载入12套基准形象”，会把新生成PNG载入工作区，重复导入不覆盖已有角色修改。
- 多视角为同一角色，不是多个剧情人物。背面和侧面为生成推演设计，后续修改应形成新版本。
- generated/内另存之前请求的DeepSeek与Codex试稿，Codex不计入上述六位角色。
