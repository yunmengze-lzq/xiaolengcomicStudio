# 111 项目问题修订

2026-10-26。没有调用文字/识图/生图模型，没有重画或覆盖111原图。

## 已定位并修复

1. **保存跳转**：旧“保存角色，去创作”按钮明确执行了 stage=0，导致保存后进入热点与来源。改为“保存角色”，只保存当前空间。已在111真实界面点击，仍停留角色与美术。
2. **角色图不符**：111已保存的角色生成提示词确实包含性格与画风，并非两者完全没有传入。但是分析要求“单人主视觉”，生成输出却选“多视图设定图”，旧提示存在冲突。分析调用现在包含性格、画风和输出视图；新增可编辑的固定外形摘要，生成时当前视图与当前要求优先。原图中的IP名称/标题不再作为分析任务的身份纠错对象。本地角色设计改用视觉摘要重新文生图，避免普通图生图继承原图版式。生成按钮前可查看实际提交内容。
3. **多角色不可生成**：上一轮将单图参考的限制错误扩展为禁止本地多人画面。已撤回这一限制，单人/多人均可按分镜文字生成。111六格按钮均实查可用，包括第2、3、4、6格的双角色场景。普通图生图仅保留为主动选择的“本格旧图修订”；旧角色参考模式载入时改选按分镜重绘，避免输入设定图后复制其分栏。多参考身份锁定仍取决于模型，不等同于支持多人画面。
4. **场景与文字不一致、莫名字样**：查看111旧首格原图，确实是三视图并带底图内生文字；它由普通图生图继承角色设定图。新本地分格使用紧凑的场景提示，包含固定外形、人物性格、动作与表情，不把心理台词直接放进可视画面；不再把设定图像素作为初始构图。显示剧情称呼与正式角色映射：蓝原柚子→deepseek娘，蓝原芽衣→codex娘。另可填写“自己的生图提示词”，原文提交而不拼接；实际提交提示可展开检查。
5. **提示词截断**：本机MFLUX源码配置max_length=512并开启截断。使用本机缓存tokenizer离线计数，111旧角色提示579 tokens，旧首格提示777 tokens，超过上限。紧凑版实测角色153/231，六格277–379 tokens（加入剧情称呼前）；后续修改的剧情称呼会少量增加长度，未做真实推理。直接输入超长提示仍受模型512 tokens限制，界面说明该边界。
6. **日漫气泡与尾巴**：按用户选择改为椭圆、细黑边、尖尾。尾巴与气泡使用同一闭合轮廓，消除独立三角形根部接缝；编辑和导出共用路径。支持左右方向和尾巴长度；尾巴纳入导出越界与占位检查。111的首格编辑界面已查看，底图保留旧版。
