# 角色、剧情与漫画表现力修订

日期：2026-10-26。本轮没有调用文字、识图或生图模型，没有新增模型请求费用。已有漫画只用于本机排版验证。

## 当前流程与状态

1. **角色档案：界面与保存已验证。** 角色与全篇画风分成两个页签，一次只编辑一位角色；模型设置、参考图分析和形象更新默认折叠。档案包含固定外形、别名、性格、动机、说话方式。参考图片分析与生成仍分别点击。
2. **剧情绑定：确定性数据链路已验证，真实编剧未验收。** 匹配顺序为角色 ID、唯一同名/别名。重名冲突不猜测。已有角色更新同步到本期已选角色；脚本生成的新角色若与库中角色唯一同名，会复用正式设定而非新增副本。台词也识别别名。编剧只接收角色所需文字，避免把图片档案和历史列表传入文本上下文。
3. **分镜表演：编辑、保存与提示词传递已验证。** 每格逐角色记录情绪、眼眉嘴表情、肢体/视线/动作和必要的心声。新脚本生成结构要求填写这些内容，心声可成为独立气泡。手动验证输入已持久化，并出现在实际生图提示词中；没有运行模型验证表演画质。
4. **角色参考出图：前置保护已验证，实际一致性未验收。** 正式图优先于画风和前格参考；新设定图、三视图、头像与表情图存为候选，已有正式图需主动采用才会改变。保持角色设计优先使用正式图，不混入最初用于重新设计的原图。缺正式图、Z-Image 固定人物却选文生图/旧图修订、或多角色同框时，会在按钮旁说明原因并阻止请求。Z-Image 仍是普通单图参考，未接入身份 LoRA/IP-Adapter，不承诺锁定身份；多角色需配置支持多参考的 API 或合适的 ComfyUI 工作流。
5. **字幕排版：已有五格作品预览已验证。** 新增源起黑体、粉圆、源起明体，保留原字体；本机按需加载，预览与导出等待加载完成。对白、心声、旁白独立；可选圆润、云朵、爆发、方框，白底黑字或黑底白字。编辑与导出共用轮廓定义，支持拖动和方向键。更新对白保留心声、旁白，以及已有对白的位置和样式；原有重叠、越界检查继续保留。编辑示意的自动换行与最终页面尺寸可能不同，以右侧成品预览为准。

## 实际验证与边界

- Web/Server 类型检查、生产构建与 diff 空白检查通过。
- 用户空间「111」仅做读取：两位角色与六格分镜的 ID、正式图路径一致；旧结构可读取，绑定保持，参考序列优先角色图。没有改写其作品。
- 在独立入口验证空间，通过真实界面填写并保存性格、动机、说话方式，磁盘读取确认保留。
- 在已有「全流程验收 · 2026-10-23」作品，通过界面保存一格情绪、表情、肢体和心声；实际提示词包含这些字段。
- 三种新增字体逐一生成已有五格作品的排版预览。黑底白字心声、方向键移动、保存和重载已验证。
- 发现更新对白会重置位置造成重叠，已修正为复用匹配对白的位置/样式；真实界面复验通过：更新后原位置仍为51%与约3.74%，心声未重复，五格作品仍可生成两页预览。圆润、云朵、爆发、方框均已运行本地排版路径。
- 没有运行真实编剧、图片分析、角色生成或分格生成。因此图像质量、人物长期一致性、复杂同框，以及模型生成的性格/情绪质量均未验收。

## 设计依据与字体

- [Runway 角色参考](https://help.runwayml.com/hc/en-us/articles/40042718905875-Creating-with-Gen-4-Image-References)：区分身份参考与画风参考，以具体动作/表情说明新画面，不将静态设定姿势当作本格动作。
- [Clip Studio 漫画设计](https://www.clipstudio.net/en/comics-manga/design-tips/)：对白与画面留白、阅读顺序一同规划。
- 字体取自 [ButTaiwan 源起黑体](https://github.com/ButTaiwan/genyog-font)、[源起明体](https://github.com/ButTaiwan/genyo-font)、[justfont 粉圆](https://github.com/justfont/open-huninn-font) 官方仓库。原始字体和 SIL OFL 1.1 许可证随软件保存，详见 `apps/web/public/fonts/fontSources.md`。TC 字形与简体地区字形可能不同，缺字由系统字体回退。
