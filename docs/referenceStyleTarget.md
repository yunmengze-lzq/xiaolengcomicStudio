# 用户参考：生活日漫四格

2026-10-26。目标以用户本轮上传的四格页面为准：自然动漫比例、细线与柔和赛璐璐、头发分束高光、生活化室内背景、明确的情绪与动作、过肩/近景/中景变化、椭圆白底黑边尖尾气泡、2×2阅读顺序。参考视觉语言，不复制人物、原剧情或台词。参考图本身未作为公共预设图片打包；本地归档副本在 `outputs/identityTrial/styleReference.jpg`。

## 已定位的实际冲突

- 前一版本本机多参考 `identityPanelInput` 没有使用选中的全篇画风描述/图片，仅要求匹配角色参考；画风选择因此不能在这条路径中发挥预期作用。
- 角色非本地长提示用 `character.artDirection || style.description`，旧的非空角色画风会排除全篇画风；角色参考收集也在有角色画风时排除了全篇风格参考图。
- 为追求身份保持，上一轮多参考提示固定默认左右排序，并要求用同框图作为构图基础，可能加强跨格静态站姿与镜头重复；这与用户参考里的视角和表演变化不符。
- 111正式角色图目前仍含Q版和多视图拼排。全局改成自然比例，不会自动把旧角色图转换为新比例；必须先确认同一画风的新角色资产，再验收成品。不能只改提示词并宣称已实现。

## 本轮修改

- 新增“生活日漫四格”文字预设：自然动漫比例、细线、柔和赛璐璐、表情戏、生活背景、四格起承转合及对白留位。独立入口不冒用旧预览图或用户图片作为生成样张。
- 多参考出图带入全篇画风短描述；有空余参考位时加入一张风格图，明确仅参考线条、上色和氛围，不引用里面的人物、文字、构图或剧情。角色参考始终保留；角色+画风+连续性图最多四张，容量不足时不额外加入连续性图。
- 角色设计全篇画风优先，保留角色画风为补充；本机klein使用紧凑角色提示。重新设计收集参考时不再因角色画风字段非空而排除风格参考。
- 去掉默认固定左右站位；前图只提供身份、衣服、道具连续性，要求按新分镜改变动作、镜头与背景。不能将这种提示约束视作模型执行保证。
- 编剧要求明确动作/道具归属，按剧情变化镜头，预留不遮脸、手、道具的对白区域；选生活日漫四格时要求恰好四格，用户已有剧情仍优先保留。
- 预设应用到当前作品时设置每页四格、暖白底、可移动气泡叠加模式。通过真实界面已应用至111；旧画风版本、正式角色图和历史图片保留，不自动调用模型。

## 验证与未完成部分

Web/Server既有类型检查、构建、diff空白检查通过。已在真实界面点选预设，随后读取作品文件确认全篇画风与四格设置持久化。没有调用文字、识图或图片模型，没有生成新图片。

因此尚未验收：目标画风的新角色、多角色身份与该画风同时成立、镜头变化与动作服从、四格成品的视觉质量。页眉、精确格间距、参考图中的手机界面等也未做成专门模板。后续应先确认两位角色的新画风资产，再做一格有明确动作与视角的双人画面；通过后再完成四格，不批量盲抽。
