# 核心创作流程改造记录

2026-11-08。根据《小冷漫画改造需求》实施代码改造；本轮不执行功能验收，不调用文本/图片模型。

## 本轮完成的代码变更

| 板块 | 原行为 | 本轮处理与原因 |
| --- | --- | --- |
| 创作导航 | 预览和导出分为两步 | 主导航收敛为六步，成品、发布文案、导出集中在最后一步，旧阶段编号继续兼容 |
| 找剧本 | 固定跨五个平台，深入研究另开页面 | 五平台多选并保存偏好；研究素材在当前页展开，收集正文、笔记、来源保留；未取得正文仍明确标注标题线索 |
| 内容方向 | 选梗统一使用反转结构 | 喜剧、科普、情感剧情及独立语气传至服务端；候选记录生成时的方向，采用时带入脚本，不随之后的筛选条件错配 |
| 角色与画风 | 已有公共库、剧本对应表、绑定后姓名同步 | 保留这些能力与用户素材；移除创作页重复模型表单，只展示当前服务摘要和统一设置入口 |
| 制作管理 | 删除整页藏在高级菜单，缺少画格删除 | 删除入口可见；删除前保存 compositionBackup 时间戳快照，保留原图；当前编辑会话可撤销上一次删除；画格删除同时移除整页关联 |
| 多页导航 | 窄屏强制横向滚动 | 整页和分格列表均保留纵向排列；窄屏可收起列表；列表和画布分别滚动 |
| 拼页气泡 | 编辑用 DOM/CSS，导出用 Canvas | 共用 drawPanel 和 panelFrame，以实际成品画格尺寸绘制编辑画布和命中区域；支持拖动、键盘移动、局部字号、宽高及整体缩放，保留竖排、样式、心声、尾巴与字体 |
| 模型与生成 | 多个配置页面来回切换 | 一页呈现模型库与任务分配；文本、图片分析、生图分别选择；本地安装仍复用原有引导；状态诊断折叠 |
| 在线生图 | 单一 imageApi 配置 | 每次新增兼容 Images API 生成独立服务 ID，可命名并分别保存地址、密钥、模型；模型下拉显示服务名和实际模型名；旧配置仍兼容 |
| 预览与导出 | 文案与成品分离 | 同页编辑文案、生成候选和导出；从已有成品页选择封面，发布包附 cover.png，不增加生图调用 |
| 等待状态 | 最后步骤没有统一文字任务提示 | 文案生成也显示任务等待反馈，不虚构进度百分比 |

## 2026-11-09：按任务重新组织界面

上一版虽做合并，但仍把模型库、配置表和安装说明纵向堆叠；搜索范围同时存在多选和单选，拼页仍主要在单格中操作。本轮重新安排交互：

- 设置默认显示编剧、图片分析、生图三张独立任务卡。服务管理和本地安装按需进入，配置后返回任务分配，不再把所有表单放在一屏。
- 文本/视觉新增服务入口统一。提供 DeepSeek、OpenAI、Claude、百炼、硅基流动、Ollama、LM Studio 和自定义兼容地址预填。内部服务 ID 自动生成；凭证仍存入既有设置。预填地址仅供开始配置，用户须按地区、工作区和供应商要求修改。
- 连接检测读取模型列表或本机状态，不生成内容。文本真实试运行单独放在高级诊断中并标明可能计费；图片 API 返回模型列表不代表支持参考图或已生成成功。
- 本地页明确区分已有服务、安装指引、MOSS。MOSS-Image Base/SFT 可通过已有 ComfyUI 接入；新增官方安装、Mac 与工作流链接，未自动下载 MOSS，也没有实现独立 CharRef 适配。
- 找剧本明确分为多平台关键词搜索、单平台热榜。采集与 AI 提案分成两个主动操作，搜索不隐式调用编剧。热榜模式不携带另一模式的关键词。
- 拼页改成页面导航、整页画布、选中画格/气泡属性。顶部可直接选单格、双格、四格模板；在整页上点击画格，拖动气泡和拉右下角手柄。编辑与导出共用完整页绘制函数，尺寸缩放按页坐标转换；局部参数和全篇参数分开。
- 气泡宽度不再被固定 190 像素限制；高度不足时按文本所需最小高度保留，避免直接裁掉对白。保留文字过多和重叠提示。
- 预览与导出改为左侧单页成品预览、右侧图片/发布包导出与文案编辑；来源自审及发布记录折叠。未生成整页显示原位置占位，防止跳过后页码与封面序号错位。

检查：前端类型检查与构建；浏览器检查搜索、设置任务/服务导航、供应商类型下拉、取消新增后返回任务配置、拼页和预览布局，并检查 760 px 窄屏设置布局。检查期间暂切分格模式后已恢复原整页模式，没有点击搜索、计费试运行、文案生成或生图；未进行真实 API 生成或多角色一致性验收。已有 /api/connection/connection 404 与打包分块体积提示不属于本轮改造。
