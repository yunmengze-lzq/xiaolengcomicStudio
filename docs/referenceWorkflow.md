# 参考图、素材库与模型配置修订

2026-10-26。本轮没有调用图像分析、文字生成或图片生成模型，没有新增付费模型请求。

## 问题与改动

1. 此前验证上传时使用了预设图库原图，不是生成的 DeepSeek 娘。角色卡现在将生成预览、直接导入成品、参考原图和分析结果区分显示；已有成品可直接转为设计参考，不重复保存文件。
2. 原本本地普通图生图会保留原图构图，加上固定种子，容易生成高度相似的图。本轮将重新设计、保持角色、纯画风参考分开；重新设计和纯画风先分析参考图，保留可编辑分析结果，再生成。本机 Z-Image 使用提取的设计文字重新文生图，只有保持角色/旧图修订走普通单图参考。不能把普通图生图称为语义风格迁移或身份锁定。
3. 角色可以提取元素和画风来重新设计，支持头像、全身立绘、设定图、正侧背三视图、六种表情参考图。角色与画风页顶部统一选择图片分析服务和设计出图服务；分析可沿用支持图片输入的文本模型，或独立选择已登录 Codex。分析与生图分别点击、分别产生用量。
4. 漫画出图将正式角色图放在参考序列前面，逐张标明角色身份、纯画风和前格连续性的职责，并强调按本格动作重画。Z-Image 新增单角色正式设定图参考模式，多角色仍需多参考 API/ComfyUI；不承诺本机模型能完全保持身份。
5. 素材库扫描当前空间的 assets 文件夹，显示原图、来源方式、平台、日期、模型和提示词；支持筛选、原图下载、来源补录、可恢复回收站和原路径复用。仍被角色、画风、漫画或历史版本引用的图受到保护。平台可从已记录来源识别，也可以手动补录；未知日期不编造。
6. 分格回填直接采用服务保存的文件，修复曾额外复制一份的问题；旧的未登记文件可在素材库扫描后补录。新本地图片记录随机种子，不再固定使用同一种子。
7. 修复 ComfyUI 供应商缺少源码映射、包导出以及导出对象格式不符合加载器要求的问题。新增兼容 Images 的在线图片 API 表单，填写服务地址、密钥、图片模型ID和尺寸；文生图与参考编辑分别调用对应接口。未配置供应商账号，未进行真实在线生图验收，也不提供免费额度。
8. 漫画模式的供应商添加列表只保留直接配置所需项目，清理无关品牌与推广。许可证和上游归属仍保留在仓库文档。
9. 空间名称旁的“⋯”统一管理改名、删除和恢复；移除占满侧栏的管理按钮。创作起点只保留一组选项卡，表单位于选项卡之后；切换后重置滚动位置，减少重复内容与滚动锚定。

## 存储位置

- 图片：`小冷漫画目录/data/workspaces/<空间ID>/assets/`。素材库显示该空间的实际绝对路径。
- 剧情、设定、素材档案：同空间内 `comicProject.json`；修改快照也保存在该空间。
- 内置本地环境、模型缓存：`data/localModels/zImage/`，可在本地模型设置检测并查看路径。
- 任务缓存：`data/comicJobs/`，与正式作品图片分开。
- 空间删除和素材回收站均是可恢复操作，保留磁盘文件，不会释放磁盘。没有自动清理共享模型、任务缓存或其他空间的文件。
- 预设展示样张另在 `apps/web/public/styleExamples/`，不是个人生成结果。

## 本轮实际验证

- Web/Server 类型检查与生产构建通过；空/越界图片分析路径返回 HTTP400，未调用模型。
- 点击“我的剧情”后读取真实布局：页面 scrollY=0，选项卡位于表单上方。
- 真实素材库列出验证空间的两张已有图片及目录；日期筛选可排除记录。
- 引用中的图禁止移入回收站。解除验证角色引用后，图片可回收、恢复，再从素材库按原路径重新引用；磁盘仍只有原来的两张PNG，没有新增复制文件。
- 本地 Z-Image 检测返回已就绪和实际模型目录；在线 API 与 ComfyUI 表单均能打开，配置字段和安装源已校验；两个供应商源码在只读校验接口均返回HTTP200（各1个模型）；未填密钥、未提交新供应商。
- 参考模式、角色视图和未分析保护已在界面检查；没有真实调用视觉分析或生图，所以实际分析准确性、参考重设计效果、在线生成，以及按角色图执行动作的画质尚未验收。

## 依据

参考职责区分借鉴 [Runway 参考媒体说明](https://help.runwayml.com/hc/en-us/articles/52963720640275-Using-reference-media-to-guide-your-generations)。在线适配使用 [Images 编辑接口格式](https://developers.openai.com/api/reference/resources/images/methods/edit)，兼容服务仍需以供应商实际支持的模型、尺寸和端点为准。本地参考强度语义核对了当前安装的 MFLUX Config 实现，重新设计改用分析文字文生图，不把调强度等同于已解决语义理解。
