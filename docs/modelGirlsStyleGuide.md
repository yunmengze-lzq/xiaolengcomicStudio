# 模型娘双形态画风与基准规范

来源：用户在2026-10-28提供的六张左右对照设定图。本规范先分析原图，再约束重新生成的多视角素材；收集原图不作为最终基准图。

## 共用的绘制语言

- 清楚而细的动漫轮廓线，局部线条颜色随头发、布料变化，不使用粗黑剪影外框。
- 柔和赛璐璐体积阴影，肤色偏浅、少量腮红，头发有大块分束高光；避免照片皮肤和塑料3D。
- 大而清亮的眼睛，有渐变瞳色和少量高光，嘴鼻简练，角色之间保留眼色与表情差别。
- 服装有层叠结构、蕾丝、褶边、少量金属件；漫画远景允许简化纹样，不能换掉识别性的服装与配饰。
- 基准图使用白底、中立清楚的姿态；分镜改为剧情动作与场景，不复印整张设定表。
- 图片不带标题、角色名、角度标签、签名或水印；文字由软件排版层处理。

## Q版画风

以原参考右侧的短身比例为准，目标约3至4.5头身，大头短身、圆脸、短小四肢，眼睛在脸部占比更大；头发、耳角翼尾保持完整识别轮廓。服装层次缩短而非删除，饰品和纹样适度压缩，表情更直接。Q版在这里表示绘画比例，不据此推断人物实际年龄。

生成约束：保持同一角色、同一形态、同一套服装；禁止混入左侧高挑成人比例；禁止把参考图左右两个人都画进分镜。

## 成人版画风

目标约6至7头身，成年动漫人物的自然体态和较修长四肢；五官仍是精致日漫，不转成写实照片。长发和裙摆有更完整的长度、层次与褶皱；手持道具、首饰和物种特征保持稳定。服装遵循原参考，不凭空改成另一套职业装。

生成约束：禁止大头短身Q版比例；成人版与Q版分别存为独立档案，不能仅用一个提示词开关混作同一份基准。

## 新生成的基准素材

每位角色分别生成Q版和成人版，共12套独立PNG。通常包含正面、侧面、背面、四分之三视角，部分附脸部特写。DeepSeek的首套Q版包含正面、侧面、背面与头像特写。侧面、背面和新增视角是依据正面参考推演的设计，不能声称是原作者已确认的背面设定。

使用顺序：选角色 → 选形态 → 载入该形态的多视角PNG → 画面提示词补充动作、表情和场景。一次只把这一个身份作为一个剧情人物，不把设定图中的多个角度当作不同人。
