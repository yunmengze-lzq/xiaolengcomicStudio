# 选题、选角与多页制作调整（2026-11-05）

## 问题与改动

1. 原选梗只读取单个平台刚刷新的标题，并限制为六个单冲突反转方案。新增主题跨平台检索，复用抖音、B站、小红书、弱智吧、豆瓣接入；最多补充三条可读的小红书正文，合并去重并交替抽取各来源，最多输出十二个原创改编提案。检索或正文失败保留标题和状态，不假称取得视频剧本。选题会关联其研究素材包。
2. 编剧显式区分反串喜剧、科普教学、情感剧情，长度可选2–12格。反串要求立场反差、升级与回扣；科普重视问题、机制、例子和边界；情感关注欲望、潜台词和关系变化。取消画风名称强制四格的约束。
3. 已复现111角色ID正确但文字仍为旧名。绑定现在同步剧情、分镜动作、对白、心声与自定义出图提示词；旧作品有一键同步入口，简称可显式补充到别名。已生成图片不会被改字，需按新设定重绘。
4. 整页模式可自动补齐分页、显示待生成页数、连续生成缺图页，并在本页完成后停止；每页完成即保存，既有图不被批量覆盖。逐页重绘仍走候选对比。
5. 分格模式改为缩略图选中一格编辑，绘制、拼页气泡、成品预览提供连续入口，减少长列表查找。

## 后续内容验收标准

同一素材分别写喜剧、科普、情感三份短稿，按具体冲突、可画性、递进、角色声音、结尾回扣/知识准确性/情绪细节分别评审。对缺正文素材保留“原创提案”标签。未来扩展视频字幕需独立的数据能力，不把当前笔记文字读取等同于视频转写。
