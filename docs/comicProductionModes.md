# 漫画制作双模式（2026-10-29）

## 修改原因

旧流程把所有图片都当作无字单格，导致已绘好对白的整页漫画再次被拼格、叠字。111 的现有图片中实际存在这种情况。整页和单格必须有独立输出，而不只是调整按钮名称。

界面参考 Clip Studio 的画框、气泡、文字分工：
- https://help.clip-studio.com/en-us/manual_en/540_comic/Balloons.htm
- https://help.clip-studio.com/en-us/manual_en/540_comic/Frames_and_Panels.htm

## 使用方式

侧边栏保留一个“漫画制作”入口。

- **整页直出**：添加一页 → 勾选 1–6 个分镜 → 检查场景与对白 → 选择横排/竖排 → 生成本页。模型负责画框、人物、气泡和文字。修改台词后重绘，候选与旧版比较后采用。支持导入整页、查看与恢复历史图，以及将已有分格图片直接作为整页使用。
- **分格制作**：生成无字人物与场景 → 同一区域进入“排版与气泡” → 调整画面顺序、每页格数、上下/左右拼接、间距、文字与气泡 → 成品预览与导出。文字仍可独立编辑。

每种模式保存独立图片。切换模式不会清空另一种输出。当前模式决定预览和导出；整页导出保留原尺寸，不追加气泡、画框、页码或第二次拼页。分格成品保持 1080×1440。

## 数据与生成

- 老作品默认 `productionMode: panels`、`directPages: []`，不转换或覆盖老图。
- 整页通过稳定的 `panelIds` 引用分镜；输出、候选、历史与分格图片分开保存。
- 整页提示词包含每格动作、人物身份、表演、对白、旁白、音效、全局画风和页面修订要求。不会复用禁止文字的单格提示词。
- 整页台词、画风等改变后显示旧版提示；采用候选前核对生成输入，防止采用与当前设定不符的候选。
- 素材库保护整页正在使用、候选及历史图片。移除页面不删除原始素材；修改记录仍通过项目日志保存。
- 气泡去掉投影，采用细黑描边；竖排在 Canvas 实际输出中按列从右到左绘制，常见括号等标点转为竖排形式，不只是 CSS 预览。

## 本轮验证与限制

- 前端类型检查、生产构建通过。
- 浏览器实际完成模式切换、添加整页、选择分镜、已有成品导入、预览、PNG 导出、删除临时页编排、返回分格排版与竖排预览。
- 整页导出与导入的已有 1080×1440 成品逐像素相同，没有重复叠字。
- 没有调用文本模型或图像模型。整页生成接口已接入既有模型服务，但本轮未验证任何模型的新生成质量；中文错字、多人物一致性、漏格仍取决于模型。
- 本地 Z-Image 仅支持单参考，Klein 最多四参考；不会为了运行而静默丢弃人物参考。
- 当前分格拼页支持规则网格、上下和左右排列，不含自由多边形画框或任意缩放画格。
- 竖排以中文逐字排版为主，不是完整日文出版排版引擎。编辑画布是定位示意，最终字号与重叠检查以成品预览为准。
