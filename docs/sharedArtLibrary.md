# 公共角色与画风库

2026-10-28。本轮按用户要求完成后备份，后续界面及功能验收由用户进行；停止追加浏览器和生图验证。

## 使用方式

- 角色与美术 → 角色档案：直接浏览公共角色卡片，搜索、新建、编辑、删除；删除移入回收站，可恢复。
- 角色档案保存名称、正式形象、参考图、外形摘要、性格、动机、对白语气及别名。生成工具收在编辑窗内，上传成品无需重新生成。
- 角色与美术 → 全篇画风：首先展示“我的画风”的实例图和描述；新建、编辑可上传图片，或用提示词/参考图生成一张，再保存回画风库。没有样张的旧文字画风明确显示“暂无实例图”。
- 外部网络案例区已移除。少量文字预设仅作为底部折叠的创作起点，选择后进入编辑，不直接替代用户保存的画风。
- 六位模型娘的十二套形象及两种画风作为一次性内置内容自动入库；不再需要“载入12套”按钮。删除的内置条目不会在刷新时重新出现。

## 公共库与作品的关系

公共库保存在 `data/workspaces/artLibrary/library.json`，图片在同目录的 `assets/`。所有本机创作空间共用这份库；它不是云账号共享服务。

首次初始化从本机已有漫画项目收录角色和画风，并复制实际引用图片。相同ID默认采用最近保存项目中的记录，不覆盖原项目；有素材迁移失败会显示提示。老项目中的不同副本仍留在原项目内。

点击“用于当前作品”会把所选档案与图片复制到当前项目，并更新本期角色名单或画风快照。旧分格图片不重画；新增角色不会擅自替换分镜中另一个角色的ID。剧情使用哪些角色仍以分镜绑定为准。

编辑或删除公共档案不会自动修改其他项目、旧脚本或已出图。需要更新某个作品时，再次应用；删除仅隐藏公共库条目，不删除文件，也不释放磁盘空间。

公共库保存使用文件版本校验及原子写入。遇到其他窗口已修改的冲突会保留当前编辑并报错，避免静默覆盖；关闭有改动的编辑窗需确认放弃。

## 备份与迁移

GitHub保存程序源码和随程序分发的内置素材。`data/`中的公共库、自定义图片、个人作品和模型不进入Git，换电脑需另行复制 `data/workspaces/`。不要上传个人设置、密钥、Cookie或本机模型缓存。
