# 自动化漫剧流程设计

日期：2026-10-27
目标：把现有“漫画工作台”扩展成可自动产出“动态漫画 / 漫剧”的流水线，同时保留人工审稿闸门。

---

## 1. 两种“漫剧”，成本差 10 倍

### A. 2.5D 动态漫画（推荐先做）

- 素材：现有分格图 + 气泡 + 旁白
- 动效：镜头推拉、视差、轻微摇镜、气泡逐字出现、拟声词弹出
- 声音：TTS 配音 + 音效 + BGM
- 视频模型：**不需要**
- 成本：低，主要是 TTS/剪辑/人工时间
- 稳定性：高，画面不会“脸崩”

### B. AI 视频漫剧

- 素材：关键帧 + 图生视频模型
- 动效：真实运动、镜头运动、口型/表情
- 视频模型：Wan 2.2 / Seedance 2.0 / Kling / MiniMax H3
- 成本：按秒计费，3 分钟 1080p 可能 $122/次，重抽后 $250+
- 稳定性：中低，需要逐镜抽卡和人工筛选

**建议：先做 A，跑通日更；只对 hero shot 做 B。**

---

## 2. 推荐流水线

```text
选题/剧本（Codex / 文本 API）
  ↓
结构化分镜 JSON（panelId、动作、对白、旁白、sfx、时长）
  ↓
角色参考 + 分格出图（本地 ComfyUI / 在线图片 API）
  ↓
排版成品页（现有工作台；或逐格 3:4 图）
  ↓
审稿闸门（4/4 通过才继续）
  ↓
TTS 配音（按角色声线）
  ↓
时间轴（每格停留、气泡出现、SFX）
  ↓
2.5D 合成（FFmpeg / Remotion）
  ↓
字幕 + BGM + 音效
  ↓
MP4 输出 + SRT + 发布文案
```

---

## 3. 数据要求

现有 `episode.json` 已经包含大部分数据：

- `panels[].image`：分格图
- `panels[].dialogue` / `speech[]`：对白、气泡、说话人
- `panels[].caption`：旁白
- `panels[].sfx`：拟声词
- `layout`：每页格数、字体、字号、文字模式、漫画质感
- `castSnapshot[].name`：角色名，可用于分配声线

还需要补：

- 每格目标时长（秒）
- 每格镜头运动（推/拉/左移/右移/静止）
- 每个角色的 TTS 声线 ID
- BGM/音效轨
- SRT 字幕时间轴

---

## 4. 自动化分级

### L1：自动生成 + 人工审稿（推荐）

- 自动：剧本、分镜、出图、排版、导出
- 人工：选角、选图、审稿、发布
- 风险低，适合日更

### L2：自动生成 + 自动预检 + 人工抽检

- 自动：生成 + 角色相似度/OCR/气泡重叠检测
- 人工：只处理失败格
- 需要 QA 服务和阈值

### L3：全自动无人值守

- 自动：生成、审稿、配音、合成、发布
- 风险：角色崩坏、事实错误、平台合规
- 不建议在未建立稳定 QA 前使用

---

## 5. 2.5D 合成方案

### 方案 1：FFmpeg（轻量）

- 对每格图做 `zoompan` 缓慢推拉
- 用 `xfade` 做转场
- 用 `drawtext` 烧字幕，或输出 SRT
- 用 `amix` 混 BGM/音效
- 优点：无需前端、可脚本化、便宜
- 缺点：复杂动效和气泡动画难做

### 方案 2：Remotion（推荐）

- React 组件描述每一格、气泡、SFX、时间轴
- 可以精确控制气泡出现、文字逐字、镜头缓动
- 输出 MP4；可复用现有页面设计
- 优点：动画精细、可版本化
- 缺点：需要 Node/React 工程

### 方案 3：剪映/CapCut 模板

- 人工最少，但自动化程度低
- 适合先验证内容，不适合大规模无人值守

---

## 6. TTS 与字幕

- TTS：Edge-TTS（便宜/本地）、Fish Audio、OpenAI TTS、火山/阿里云
- 每个角色绑定固定声线
- 旁白单独声线，语速略慢
- 气泡文字按 TTS 时间轴逐句出现
- 字幕单独输出 SRT，避免和画面内气泡重复
- 字幕断句按语义，不按字数硬切

---

## 7. 调度与自动化

```text
每天 08:00 选题
  → 08:05 剧本/分镜
  → 08:10 出图（批量）
  → 08:30 排版/审稿
  → 09:00 TTS/合成
  → 09:20 导出/上传草稿
```

实现方式：

- Windows 计划任务 / cron 调 `start.ps1` + pipeline 脚本
- 或 Codex/Agent 定时任务，但需要限制 token 和失败重试
- 每次运行写 `runId`、模型版本、seed、成本、失败原因
- 失败重试只重跑失败格，不整集重跑

---

## 8. 质量控制闸门

- 角色数量 = 分镜设定
- 人脸相似度 > 阈值
- 无文字/气泡误生成
- 气泡不重叠、不超出安全区
- 对白与配音时间匹配
- 每格时长 2–5 秒，3 分钟约 36–60 格
- 人工抽检 20%，失败格回炉

---

## 9. 成本量级

详见 [costModel.md](costModel.md)。

- 静态漫画 48 格：约 $5–15/集
- 2.5D 动态漫画 3 分钟：约 $10–40/集（不含人工）
- AI 视频 3 分钟：约 $60–250+/集（含重抽）

---

## 10. 建议的下一步

先做 **20–30 秒样片**，不要直接上 3 分钟：

1. 选 4 格已有漫画
2. 写每格 2–4 秒时间轴
3. Edge-TTS 生成 2 个角色声线
4. FFmpeg 做推拉 + 转场 + 字幕 + BGM
5. 人工看一遍，确认“像漫剧”再扩展

样片通过后，再决定是否上 Remotion 和视频模型。
