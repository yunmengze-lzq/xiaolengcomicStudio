## 新用户开始方式

1. 将应用拖入 Applications 后打开，创建自己的创作空间。
2. 设置 → 本地运行环境 → 第一次使用，选择在线 API / ComfyUI / 已有 Mac MLX 环境。
3. 在线 API 最省本地环境准备：用户自行配置文本/识图模型和图片 API，再设置任务默认模型。
4. ComfyUI：打开官方安装指南，由官方安装器准备环境；在其模板中准备模型、导出 API 工作流，回到小冷漫画检测端口并连接。当前仍需配置节点映射，尚非全自动模板安装。
5. Apple Silicon MLX：先准备 Python 3.10–3.13（推荐 Python 3.12），选择 klein 或 Z-Image，阅读来源和模型要求后勾选下载确认。安装器创建独立 venv，安装 mflux 0.23.0，并下载选定权重。点击停止保留缓存，再次安装复用缓存；缺少 Python 时显示官方安装指引，不修改系统 Python。
6. 展开「已有服务与模型」，检测并设置默认模型。环境/文件就绪与实际生成成功是分开的状态。

MLX 安装仅支持 Apple Silicon Mac。权重取自 Hugging Face 上 `mlx-community/flux2-klein-4b-4bit` 或 `filipstrand/Z-Image-Turbo-mflux-4bit`；Python 包取自 PyPI。没有隐式第三方镜像、任意命令输入或开机自动下载。安装版本固定 mflux，模型仓库当前快照由下载器解析，尚未固定全部传递依赖与权重哈希；正式发布应补版本锁定及完整性清单。

安装任务的阶段日志位于 `localModels/zImage/installation.log`；不保存下载器原始输出、环境变量或密钥。关闭应用会中断任务；重开后以文件检测为准，点击安装继续。当前显示阶段进度而非精确百分比。已验证已有模型的无下载复用、非法模型拒绝和外站来源拒绝；未在干净机器验证完整下载、磁盘不足和中途停止。

## 数据与分享边界

桌面版数据独立于安装包：

- macOS：`~/Library/Application Support/xiaolengComic/data`
- Windows 设计路径：安装目录下的 `data`，与安装器的重装、卸载逻辑保持一致，未在 Windows 真机验证。
- 开发环境继续使用仓库 `data`；可通过已有 `TOONFLOW_DATA_DIR` 指定目录。新桌面包不会自动导入开发目录，避免把个人数据带给朋友。

应用包不包含开发机的项目、角色库、平台登录、API 密钥和模型权重。自己迁移时应先备份数据，再选择性迁移项目与资源；不要把整个个人 data 发给朋友。普通 GitHub 源码备份同样不包含 data。

产品显示名改为小冷漫画，独立应用标识为 `local.xiaoleng.comic`，默认更新源改为本项目 GitHub。尚未发布符合更新器格式的 Release，暂以重新安装测试包更新。内部 Toonflow 模块和兼容协议保留；原项目 LICENSE 和第三方许可继续保留。

## 桌面应用与服务器的选择

当前建议先发桌面测试包：现有代码是本地工作区设计，角色库、模型密钥和平台登录以单个用户数据目录存储；桌面最容易复用每位朋友自己的本地服务。

当前设备配对机制不是多用户账户/租户隔离。直接公开服务端不能替代账户权限、每用户文件与密钥隔离、任务队列、资源配额和下载鉴权。服务器版适合后续统一维护，但需先完成这些改造，且集中 GPU 或 API 成本由运营方承担。本轮未对公网部署。
