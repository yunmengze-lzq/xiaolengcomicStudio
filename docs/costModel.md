# 漫画 / 漫剧在线成本测算

日期：2026-10-27
币种：USD；人民币按 `1 USD ≈ 7.1 CNY` 粗略换算。
说明：以下是公开列表价的量级估算，不是报价。实际以供应商账单、促销、批量折扣、重试次数为准。

---

## 1. 先分清四类成本

1. **文本 token**：编剧、分镜、提示词、审稿、文案。
2. **图片生成**：每格每张图，按张计费。
3. **视频生成**：每秒计费，是“漫剧”真正的成本大头。
4. **重试与人工**：废图重抽、候选筛选、配音、剪辑、字幕。

一个常见误区是只算“一张图多少钱”。实际成本通常是：

```text
单集成本 = 图片单价 × 格数 × 候选数 × (1 + 重试率)
         + 视频单价 × 秒数 × 镜头数 × 重试率
         + 文本 token 成本
         + 配音/剪辑/人工
```

## 4. 每集文本 token 估算

按 48 格一集估算：

| 档位 | 典型做法 | token/集 |
| --- | --- | ---: |
| 精简 | 一次结构化编剧 + 模板生成每格提示词，不做逐格视觉 QA | 3 万–8 万 |
| 标准 | 编剧 + 逐格视觉 QA + 发布文案 | 15 万–30 万 |
| 重度 Agent | 每格单独调用、工具循环、失败重试、长上下文 | 50 万–100 万 |

注意：Codex/Agent 的“token used”会把系统提示、历史上下文、工具结果重复计入。
**同样一集，Agent 循环越多，token 可能比实际文本内容大 3–10 倍。**

| --- | ---: | ---: | ---: |
| GPT-6 Luna | $0.10 | $0.50 | 约 $0.22 |
| GPT-6 Sol | $2.00 | $10.00 | 约 $4.40 |
| GPT-5.6 Sol | $2.00 | $10.00 | 约 $4.40 |

参考：

- GPT-6 Luna：<https://benchgecko.ai/model/gpt-6-luna>
- GPT-6 Sol：<https://benchgecko.ai/model/gpt-6-sol>

### 每集文本成本

| 档位 | GPT-6 Luna | GPT-6 Sol |

## 5. “一整天 Codex”大概多少 token

先明确：
**Codex CLI 用 ChatGPT 登录时，不是按 token 计费，而是消耗订阅额度/速率限制。**
只有走 API key 时，才按 token 计价。

### 按 8 小时工作日估算

假设 1 小时产出一集 48 格：

| 档位 | 8 集 token | GPT-6 Luna 成本 | GPT-6 Sol 成本 |
| --- | ---: | ---: | ---: |
| 精简 | 24 万–64 万 | $0.05–0.14 | $1.06–2.82 |
| 标准 | 120 万–240 万 | $0.26–0.53 | $5.28–10.56 |
| 重度 | 400 万–800 万 | $0.88–1.76 | $17.6–35.2 |

### 按 24 小时连续估算

假设 24 集、每集 48 格：

| 档位 | 24 集 token | GPT-6 Luna 成本 | GPT-6 Sol 成本 |
| --- | ---: | ---: | ---: |
| 精简 | 72 万–192 万 | $0.16–0.42 | $3.17–8.45 |
| 标准 | 360 万–720 万 | $0.79–1.58 | $15.8–31.7 |
| 重度 | 1200 万–2400 万 | $2.64–5.28 | $52.8–105.6 |

**但“24 小时连续”通常不是 token 先到上限，而是：**

- 图片 API 限流/排队
- 视频任务几分钟到十几分钟一条
- 人工审稿/重试
- ChatGPT 订阅额度先耗尽

所以真正做自动化，不建议用“时间”估，建议用“每天多少集、每集多少格、每格几次调用”估。

## 8. 哪种方案更合适

### 如果目标是“稳定日更漫画”

推荐：

```text
文本：GPT-6 Luna / Qwen-Flash 等便宜模型做结构化编剧
图片：Qwen Image 3.0 批量草稿 + Seedream 5 Pro 关键格
封面：Nano Banana Pro / GPT-image-2 high
本地：角色 LoRA / 角色卡 / 免费变体
```

理由：

- 静态漫画图片成本极低，Qwen 3.0 约 $0.025/张。
- 主要成本不是 API，而是重试、审稿和排版。
- 4 候选/格是质量保障，普通格可以降到 2 候选。

### 如果目标是“AI 漫剧”

推荐顺序：

1. **先做 2.5D 动态漫画**：静态图 + 推拉/视差 + 配音 + 气泡动效。
   成本低、稳定、可日更，不依赖视频模型。
2. **hero shot 试图生视频**：Wan 2.2 480p 做预演，Seedance 720p 做最终。
3. **不要整集 1080p 视频模型铺开**：3 分钟 1080p Seedance 单次就 $122，重抽后 $250–500。

### 如果目标是“纯本地、零 API 成本”

- 静态漫画：可行，但 8GB 显存限制大，角色一致性需要 LoRA/ControlNet，出图慢。
- 漫剧视频：本地 8GB 基本不现实，Wan/Seedance 级别模型需要更大显存或云。
- 适合：草稿、构图、角色参考、免费变体；不适合作为最终画质主力。

## 9. 最省钱且不牺牲太多的组合

| 环节 | 建议 |
| --- | --- |
| 编剧/分镜 | GPT-6 Luna 或 Qwen-Flash，结构化 JSON，一次调用生成整集 |
| 每格提示词 | 代码模板生成，不要每格都调 LLM |
| 普通格出图 | Qwen Image 3.0，2 候选 |
| 关键格/封面 | Seedream 5 Pro 或 Nano Banana Pro，4 候选 |
| 审稿 | 先人工筛，再用便宜视觉模型做 OCR/角色数量检查 |
| 视频预演 | Wan 2.2 480p |
| 视频成品 | Seedance 2.0 720p，只对 hero shot |
| 动态漫画 | 2.5D，不调用视频模型 |

按这个组合，**一集 48 格静态漫画的 API 成本通常能控制在 $5–15**；
**一集 3 分钟动态漫画约 $10–40**；
**一集 3 分钟 AI 视频漫剧约 $60–250+**，取决于分辨率和重抽次数。

---

## 10. 一句话结论

- **在线静态漫画不贵**，Qwen Image 3.0 把单格成本压到约 $0.025。
- **贵的是视频**，3 分钟 1080p Seedance 一次就 $122，重抽后 $250+。
- **Codex 的 token 不是主要成本**；按 GPT-6 Luna 算，一天重度使用通常也就几美元。真正的限制是速率、图片/视频额度和人工审稿。
- **最合适的是混合**：便宜模型做批量草稿，高质量模型做关键格/封面，视频只做 hero shot，先上 2.5D 动态漫画。
