# 编辑与预览流程修正 · 2026-10-29

## 问题与处理

1. 角色/画风编辑将图片和文字混为一个入口。现在明确分为文字创作、图片参考；文字方式不传旧人物图片，图片方式要求参考图片。统一在整理设定后微调、生成预览。保留名称、描述、性格；动机、对白、别名、服务详情和图片管理折叠。
2. 选入演员名单不等于分格绑定。增加“剧本人物→固定形象”对应表，存储到本期roleBindings；关联分格出场、对白说话者和表演ID。另保留逐格微调。更新同一角色不会重建分镜分配；移除角色清理对应关系。生成图片不再偷偷用项目旧档案覆盖本篇角色快照。
3. 旧画风干扰：本地提示词画风过短、位置靠后，旧画面继续作为参考。画风描述前置并扩展，参考身份与渲染画风职责分开；输入变化后不再携带旧画面；使用最近的画风样张。自定义提示词会覆盖自动提示词，有明确提醒。已有图片必须重绘才会改变；未声称模型一定精确遵循画风。
4. 字幕区去掉重复脚本对白框，一次选择一个气泡编辑。基础保留角色、用途、文字；形状、颜色、宽度和尾巴折叠。旁白/音效和页面细节折叠。移除根据感叹号擅自将椭圆变成爆发形的渲染行为。
5. 缺图作品原先显示原图与文字列表，未运行排版合成。预览现在与导出共用renderPages，缺图用占位背景，照常绘制气泡/心声/旁白。预览允许显示重叠并警告；正式导出仍要求图片齐全且排版可用。

## 验证

- 111项目复现缺图预览不含合成字幕，修复后显示2页合成预览，包含已有3张图与3格占位。
- UI检查文字/图片模式切换、折叠设置、单气泡编辑入口。
- UI绑定一次蓝原柚子→DeepSeek娘Q版，确认4格出场、6条台词绑定并保存；随后恢复未绑定状态。
- 仅在内存中检查两角色生成输入：2张角色参考、新画风描述存在、旧场景参考排除。没有生成新图片或调用AI分析。
- 前端类型检查与构建通过。模型最终画风变化尚未通过实际生图验证。
