# 角色与美术交互更新 · 2026-10-29

## 使用流程

- 顶部“本篇已选”显示角色和画风及已有图片，卡片显示选中边框与标记。取消选用不删除公共库、不删除已生成图片。参与分镜的角色取消时提示清除绑定，文字保留，随后可在分镜指定台词角色。
- 新建角色：上传参考图或输入一句话 → 选择已有画风 → 分析填写设定，或分析并生成一张 → 微调外形、性格、动机、对白 → 保存公共库 → 选用于本篇。支持重新设计、保持身份、只参考画风三个意图。
- 新建画风：图片或文字 → 分析 → 生成预览 → 保存。亦可关键词检索 Wikimedia Commons 案例，选中后导入并分析；来源保存到参考图记录。检索结果不等于商业授权，仍以来源页为准。
- 无预览图的旧档案明确标示“暂无实例图”，不批量生成付费图片。用户可打开档案生成预览。
- 台词角色：分镜页每条台词增加角色选择，显示性格提示。手动指定同步说话者ID、对白标签与本格出场角色。编剧原有输入包含性格、动机和对白语气，生成时按角色ID绑定。
- 整体预览替换审稿修改；完整图片自动合成排版，缺图时显示已有画面与缺失分格。直接导出PNG（多页ZIP）或发布包，无逐格审批门槛。

## 设置修正

- 模型选择不再因一次探测失败而清空或悄悄切换服务；不可用的已选服务保留名称和提示。
- 保存供应商配置后立即刷新模型列表；用请求版本避免旧的慢检测覆盖新配置。
- 图片分析显示真实文本模型名；ComfyUI区分“工作流已保存”和未就绪。已配置不代表本机服务运行或生成成功。
- Codex检测与文本、生图调用共用程序定位：PATH、常见安装路径、macOS App附带CLI、Windows npm原生程序。可用COMIC_CODEX_BIN指定绝对路径；该路径为各电脑本地设置，不写死在项目中。检查超时从2.5秒提高到6秒，失败原因展示给用户。
