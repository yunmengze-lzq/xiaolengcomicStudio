## 画风和性格不是保证效果的开关

- 画风的 description 进入角色/分镜生成提示；支持参考的服务才会利用参考图。文字预设不是专用模型或LoRA，不能把预览图当效果保证。klein紧凑提示会截取部分描述；Z-Image角色生成通路当前不传参考图。此次未逐一验证所有预设出图。
- 生成脚本请求携带绑定角色的 personality、motivation、speechStyle。服务端进一步要求用性格影响决策、用说话方式区分对白，不直接朗读设定。此轮检查了数据链路与编译，没有额外调用文本模型验收台词遵循率。
- 性格为空的模型娘不擅自填入推断性格。已存在的脚本不会因修改档案自动重写。
