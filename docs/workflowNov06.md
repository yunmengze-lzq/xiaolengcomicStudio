# 创作流程调整 · 2026-11-06

## 本次改变

- 找剧本 → 选题与脚本 → 角色与美术 → 分镜设计 → 漫画制作 → 整体预览 → 导出发布。内部阶段编号保留，导航和前后按钮使用统一显示顺序，兼容已有项目。
- 编剧接口新增 script/storyboard 两个阶段。脚本阶段只返回正文与角色清单（包含编号、姓名、说明和性格），不生成分镜。清单单独存储为 scriptRoles，已有项目默认空数组。
- 角色对应表直接展示人数、编号、剧本人物与形象预览。点击选择/更换打开公共库，选中即导入并绑定，不再要求先选入再绑定；取消留在原行。本篇性格与别名折叠微调，姓名自动同步；公共库管理折叠收纳，逐格人物操作集中在分镜设计。按原剧本人物保存绑定；新脚本所有人物绑定后才能生成分镜。已有角色改绑会替换人物 ID、姓名、表演与对白；取消时恢复原剧本姓名。
- 分镜阶段使用最终绑定人物及其性格生成，独立按钮触发；重生成前保留项目快照，成功后清空失效的整页编排，旧原图仍在素材目录和快照引用中。
- 找剧本、编剧、绑定和分镜任务等待时，显示任务名、不确定进度条与等待说明；不伪造百分比，不追加后台模型调用。
- 整页缩略图不再被挤压；导航、画面、参数区设置独立滚动边界。切页仅滚动页导航，窄窗口使用横向页导航。分格列表同样补齐高度约束和禁止缩略图压缩。
- 设置合并为模型与生成、平台与采集、界面外观；原能力保留为组内入口，窄窗口显示文字分类，避免仅凭图标猜测。

## 角色绑定交互收敛

参考 Figma 的就地替换资源方式（https://help.figma.com/hc/en-us/articles/360039150413-Swap-components-and-instances），把先选入再绑定合并为按剧本人物打开带图角色库直接绑定；保留新建、编辑与跨作品复用。主界面只展示对应关系、预览、绑定进度、更换和取消；性格与别名折叠，逐格安排移至分镜设计，公共库管理折叠。浏览器已验证现有角色图、状态与选角弹窗，未修改用户的实际角色对应关系。旧项目若混有旧名和新名，仍需用户明确绑定，不凭名字猜测人物身份；绑定后对应新名会合并显示。
