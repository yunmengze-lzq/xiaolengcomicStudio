# 小冷漫画使用说明

本软件已更新为“小冷漫画”。完整流程、双角色排字与本轮验证请先看同目录 `xiaolengWorkflow.md` 和输出目录 `xiaolengVerification.md`。下文保留已有操作说明；漫画创作入口的通用设置已改为专用“创作设置”。


基于 [Toonflow-app](https://github.com/HBAI-Ltd/Toonflow-app) 的 MIT 许可源码，新增适合静态漫画的一体化流程。原有无限画布、模型设置和素材能力保留。

## 打开软件

本机已安装依赖并构建 Web 与 Server，当前以本地浏览器运行；原生安装包和 Docker 漫画流程未验证。双击项目根目录的 `startComic.command`，浏览器打开：

<http://127.0.0.1:3187/#/comicStudio>

服务仅监听本机，匿名使用统计默认关闭。终端保持运行；退出终端会停止该次启动的服务。端口可通过 `TOONFLOW_SERVER_PORT` 指定。

项目、图片、配置保存在软件目录的 `data/`，不会提交到 Git。备份软件时请单独备份整个 `data/`。不要将带供应商密钥的配置文件发给别人。

## 一期漫画的完整操作

1. **创建项目。** 用侧栏创建漫画项目。每个项目独立保存来源、角色、风格和多期作品。
2. **热点与来源。** 默认采集抖音聚合热搜，保留榜位、热度值、采集时间和平台搜索链接；按科普、娱乐关键词筛选，或输入自己的关键词。小红书使用本人登录搜索；右上角“平台接入”可连接账号。失效的公开聚合源已从界面移除。IT之家、Solidot RSS 作为补充。热搜是线索，选题后还需补充可靠事实来源；RSS 不是热度排行榜。点击“用这个选题”创建本期作品。
3. **准备角色与美术。** 可提前进入第 4 步：上传参考图并记录来源，填写美术规范与避免效果，保存第一个风格版本。建立原创角色并上传设定图。点“绑定当前风格与角色”，把设定复制成本期快照。
4. **选题与脚本。** 打开原文核对事实；编辑事实摘要并勾选确认。填写创作方向，用“本机 Codex CLI”生成脚本和分镜，也可选已配置的文字 API。脚本和分镜均可手工编辑。重新生成前会保存旧内容的历史 JSON。
5. **分镜设计。** 修改景别、动作、人物、对白和旁白；新增分格并调整阅读顺序。角色选择使用本期绑定的角色。
6. **分格出图。** 选择已配置的图片服务逐格生成，也可连续生成全部缺失或设定已变化的分格；已完成分格会跳过，失败后已保存的结果保留。也可导出 Codex 任务包。任务包包含提示词、角色和风格参考图。在 Codex 中生成后，将图片导入对应格。每次生成或导入保留历史版本。已有上一格时也作为连续性参考；上一格换图后，下一格需要重新生成或明确确认沿用。
7. **字幕与排版。** 每页可放 1、2 或 4 格，输出 1080×1440。修改文字字号与气泡位置，点击刷新排版预览。文字独立绘制，修改对白不用重画图片。画面完整缩放，不自动裁掉人物。
8. **审稿修改。** 查看逐格画面与完整排版，记录修改意见，逐格确认通过。图片、设定、对白、事实或排版发生变化后，旧的通过状态自动失效。
9. **导出发布。** 填写文案，导出 ZIP。包含成品 PNG、文案、来源、当期配置快照和使用的图片素材；软件也在项目目录保存一份。前往小红书创作中心完成发布与 AI 标识，回来保存作品链接。

输入修改后，右上角会显示未保存状态。使用“保存”保存手工修改；生成、导入和审核等操作会保存相应结果。文件被另一个编辑器修改时会拒绝覆盖，请先保留当前修改并重新载入。

## Codex 和第三方 API 的边界

- **Codex 编剧是真实 CLI 调用**：复用本机登录，保留用户配置与规则，以只读沙箱和结构化输出执行。工作台可指定账号支持的模型 ID，初始为 gpt-6.1-sol；清空后沿用 CLI 默认，不修改全局模型配置。没有绕过权限或抓取登录令牌。
- **Codex 图片生成采用任务包交接**：本工作台没有使用非官方 Windows 图片中继，也不宣称 CLI 存在任意软件可调用的图片接口。出图后导入对应分格。
- **第三方文字和图片服务**：从“模型与服务设置”使用 Toonflow 已有供应商配置。文字生成复用已有文字接口；图片生成复用媒体供应商接口，并传入风格、角色参考图。供应商是否接受参考图、费用、限流由其实际能力决定。
- 本次未调用第三方付费图片 API，未替用户创建 OpenAI API 密钥。
- 发布是导出素材加人工发布，尚未接入平台自动发帖。

## 风格更新

参考图片、来源与备注先保存到风格草稿。正式版本保存后不可编辑覆盖。新版本不会自动替换已有默认版本；点击版本卡切换“新作品默认”。

既有作品保留原风格和角色快照。需要更新某期时，再明确点击“绑定当前风格与角色”。绑定变化会要求重新确认对应图片和审稿；旧图仍保存在图片版本中。

## 从源码运行

需要 Bun 1.3.14。按仓库原有约定使用 Bun，不混用依赖管理器。

```sh
bun install --frozen-lockfile
cd apps/server
bun run routes
cd ../..
bun run --cwd apps/web build
bun run --cwd apps/server build
TOONFLOW_SERVER_PORT=3187 bun build/server/index.js
```

如需 Codex 编剧，先安装并登录 Codex CLI。若 CLI 不在 PATH，可在启动前设置 `COMIC_CODEX_BIN` 为它的绝对路径。Mac 启动器也会尝试已安装桌面应用中的 CLI。

开发方式沿用原仓库，Web 与 Server 的类型检查命令分别是 `bun run --cwd apps/web typecheck` 和 `bun run --cwd apps/server typecheck`。

## 抖音、小红书采集

抖音接入 [60s API](https://github.com/vikiboss/60s)（MIT）公开聚合服务。本机已返回真实榜位和热度，平台链接为关键词搜索页，并非某篇原文。公共实例有严格限流，适合当前开发验证；长期运行建议按上游文档自部署。来源服务错误会直接提示，不返回伪造热点。界面显示的是采集时间，不冒充内容发布时间。

“科普线索”“娱乐线索”使用可解释的标题关键词筛选，不能保证覆盖所有内容；可选择全部，再手动搜索标题关键词。不会把未匹配到的标题擅自归类为娱乐。

小红书公开聚合 `/v2/rednote` 在本机核查时返回 500。已另外安装 [xiaohongshu-mcp v2.5.5](https://github.com/xpzouying/xiaohongshu-mcp/releases/tag/v2.5.5)（Apache-2.0）的 macOS arm64 发行包和内置浏览器。程序与登录状态位于 `data/localServices/xhs/`，二进制及登录数据不进入 Git，原许可证保存在该目录。启动器仅监听 `127.0.0.1:18060`。

1. 在任意制作步骤，点击右上角“平台接入”。抖音公开热榜直接使用，无需账号或开发者凭证；本软件尚未接入抖音账号登录和视频正文采集。
2. 小红书卡片会检查本机服务及登录状态。点击“连接小红书”，自动启动本机已安装的 `xhsServer`，并显示二维码。无需单独打开终端；`startXhs.command` 作为手动启动方式保留。
3. 在 4 分钟内由本人用小红书 App 扫码并在手机端确认；页面每 6 秒检查一次，登录成功后自动显示“本人账号已连接”。二维码有倒计时，关闭弹窗停止检查；再次打开保留有效二维码，不重复创建会话。过期后可重新连接。本机未替用户完成手机确认，不读取其他浏览器的账号。
4. 点击“开始搜索小红书”，输入“职场”“情侣”“MBTI”“科普”等关键词，点击“发现剧情梗”。检索条件为一天内、最多点赞，保留笔记链接与点赞值。它是近期搜索候选，不是小红书全站热榜。只需原始候选时，展开“查看原始话题与来源”，使用“只获取话题，不分析剧情”。

这里的连接是第三方开源工具复用本人登录会话，不是平台官方开发者 API 授权。手机端需要有本人小红书账号；没有账号时在官方 App 内自行注册。软件不要求购买所谓登录资格或向助手提交 Cookie。换机器且缺少服务时，界面提供上游安装说明，不自动下载可执行文件。

工作台只代理该服务的登录状态、二维码和搜索接口，没有代理发帖、评论、私信。完成登录和成功搜索前，不应将这条链路记作已采集成功。首次运行所需的浏览器已在当前机器安装；换机器请从上游对应发行包重新安装，不复制登录数据。

## 脚本与美术借鉴

参阅同目录 `comicAgentsResearch.md` 与 `socialSourcesResearch.md`。脚本调用在一次模型回答内依次执行编剧、导演、审稿职责：科普组织疑问、原理、边界与结论；娱乐组织铺垫、冲突、反转与收束；逐格检查动作、角色和道具连续性。一次调用不冒充三个独立运行的 agent。

美术使用固定身份描述、风格正向规范、避免项、参考图和本期快照。借鉴 StoryDiffusion 的输入组织方式，没有安装其 GPU attention 推理模型。图片生成结果仍需目视检查身份与画风。

## 本次实际成品

工作台会发现本机服务器工作区内已有的漫画项目，换浏览器后仍可从下拉框选择“热点科普 · 实际出图”。本次用抖音台风热搜线索、NOAA 科学资料、本机 Codex 编剧和内置 imagegen，完成了原创角色设定、两格新图、独立中文排字、审稿和发布包导出。

本次 Codex 出图由助手调用内置工具后导入工作台，过程及原始提示词留在输出目录 `comicPrompts.json`。这不表示软件可无人值守调用 Codex 的图片接口；配置第三方图片 API 后，才使用软件内“连续生成待出图”路径。发布包未发布到任何社交平台。

## 热门生活与剧情梗

第 1 步选择抖音来源，点击“发现剧情梗”：先获取当批真实热榜，再使用当前文字服务筛选最多 6 个适合生活漫画的方向，覆盖情感、工作、学习、哲学、科普、MBTI 趣谈等。点击“用这个方向写漫画”，开场、冲突、反转和核对要求会进入本期创作方向。

推荐卡保留热榜线索和平台热度；开场、冲突、反转是原创改编提案。只有标题时不宣称已看过视频，也不把改编剧情冒充原梗玩法。需要打开来源核对原梗内容，再决定采用。没有合适线索时允许不推荐，候选较少时不会硬凑全部类别。MBTI 只作轻松人物趣谈；科普需另核实科学知识，哲学不编造名人引语。该入口可从抖音直接开始，小红书登录是可选来源。


## 本轮使用流程优化

右上角固定“平台接入”入口，区分免登录热榜、本人扫码搜索和暂未实现的能力；接入卡片参考 Buffer 的渠道连接方式。默认突出“发现剧情梗”，原始话题及筛选收进可展开区域，有旧作品时可直接继续。科技 RSS 单独显示“获取科技资讯”，避免触发不适用的剧情梗分析。底部按钮直接显示下一站名称；未核对来源时明确提示原因。窄屏导航横向滚动，避免八个步骤占满首屏。
