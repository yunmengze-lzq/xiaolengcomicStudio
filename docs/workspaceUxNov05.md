# 2026-11-05 创作入口与漫画工作台重排

## 为什么改

旧页把标题说明、模式、模型参数、批量按钮和全部内容依次堆叠，首屏看不到作品；热点搜索和跨平台采集分散，用户难以判断下一步。

## 本轮调整

- 漫画制作采用页/格导航、中央画布、当前内容编辑。整页一次只编辑一个画面的台词；本页生成位于编辑区顶部。分页、批量生成、导入与历史版本收起。
- 分格制作按绘图、拼页气泡、预览导出推进，切换绘图与排字保留当前画格。气泡点击即选中，以虚线标识；编辑器只显示当前气泡。
- 热点入口合并为“找灵感”和“自己写故事”。关键词搜索统一入口，平台选择和原始关键词采集收进搜索范围；专题素材作为深入查找的后续页面，可返回列表。
- 自己写故事包含完整剧情、一句话想法、继续连载。角色选择按需展开。已有作品入口统一到顶部。
- 保留原图片、脚本、角色、历史和生成接口；本轮没有调用文本或生图模型，也未抓取新平台内容。

## 设计参考

- [Clip Studio Paint 页面管理](https://help.clip-studio.com/en-us/manual_en/570_pages/Page_Manager.htm)：页面缩略图与当前编辑画面分离。
- [Feedly 搜索与范围](https://docs.feedly.com/article/78-how-can-i-search-within-my-feedly)：统一搜索入口，用范围限制来源。

## 验证与边界

前端生产构建与 vue-tsc 通过；浏览器验证了模式切换、页选择、画格选择、选格后进入气泡编辑、原创入口、连载入口、素材包返回和搜索范围展开。使用现有图片检查布局，不以模型调用验证本轮 UI 调整。未验证新生成质量和实时平台搜索质量。

按用户最新要求，本轮先留在本机继续打磨，不提交或推送 GitHub。

## 脚本与分镜页（续）

- 脚本页改为正文主区和创作侧栏，正文不再被模型配置、来源和参数挤到页面下方。来源未核对时保留明确处理入口，已核对来源、角色画风和模型设置按需展开。
- 分镜改为阅读顺序导航与当前格编辑，支持在编辑时对照故事。景别、角色表演、旁白音效收纳；逐句对白与说话者放在一起，显示角色性格提示。
- 当前格使用稳定 ID 定位；通过界面将第一格下移再上移，确认始终编辑同一格并恢复原顺序。
- 生成输入修正为使用当前非空正文，包括手写与修改后的故事，而不只判断最初是否导入了剧情。服务端已有 suppliedStory 处理逻辑。未实际调用模型验证生成结果。
- 浏览器检查了脚本正文展示、分镜切换、多角色表演展开、排序恢复；构建和前端类型检查通过。没有保存测试改动到用户作品，也未推送 GitHub。

## 角色美术与制作、安装补充

- 本篇已选资源前置：头像/画风预览、角色数量、画风名和取消按钮可见。公共卡片主按钮选用/取消；更新快照收进更多，避免把编辑公共档案误当作更新本篇。
- 角色/画风编辑用左侧设定、右侧预览；创作起点和高级设定按需展开，保留参考图分析、一句话生成和性格微调。
- 剧情人物绑定集中一处，服务配置折叠到素材库之后；切换角色/画风重置搜索过滤。
- 漫画制作保留整页/分格两条路线，新增前后页/格导航、缺少模型/画风提示、空分镜引导；整页批次停止按钮移出禁用表单，生成中仍可点击。
- 本地环境入口按在线、ComfyUI、MLX 三条路径组织，旧服务检测收进同一折叠区。MLX 支持按需安装与已有缓存复用，保持生图与安装互斥。
- 分享版本、验证边界与后续计划见 sharingGuide.md；不把编译通过描述为生图质量验收。
